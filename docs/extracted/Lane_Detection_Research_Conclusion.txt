Lane Detection Research Review & Proposed Model
Purpose: Consolidated conclusion from the four reviewed papers, with a practical direction that can be shared with the
implementation team.
1. What the four papers collectively show
 Paper
Main problem
Main contribution
1. Adaptive preprocessing + fuzzy tuning
CNN lane detection degrades in rain/challenging weather.
Adaptive preprocessing; fuzzy logic tunes Canny threshold using detected-line feedback before CNN.
2. Enhanced CLRNet (GFO + ALGA)
Weak feature focus and lane-geometry handling under difficult lighting/road conditions.
GFO focuses on lane-relevant regions; ALGA aggregates local/global information using lane geometry.
3. CCCNet
CLRNet struggles with shadows, night, dazzle, no-line cases due to limited global context.
Adds Recurrent Criss-Cross Attention in CLRNet FPN to capture long-range/global context.
4. Sim-to-Real UDA
Training and deployment domains differ; unlabeled target data causes domain shift.
Disentangles lane/background features and performs selective feature alignment; masked context learning improves robustness.
2. Combined research conclusion
The four papers do not solve exactly the same problem. They improve robustness at different levels: input level
(adaptive preprocessing), feature level (GFO + ALGA), global-context level (CCA), and domain level (unsupervised
domain adaptation). This makes them complementary rather than simple duplicates.
The common research gap is that a lane detector can still fail when several difficulties occur together—for example,
degraded input from weather plus weak lane visibility plus domain shift. Therefore, a unified framework that improves
the input, lane-specific representation, and global context is a reasonable research direction.
3. Recommended proposed model
Input image → Adaptive/Fuzzy preprocessing → CLRNet backbone → GFO → ALGA → CCA → Lane prediction
Optional advanced training stage: use the disentangled domain-adaptation strategy when source and target
domains differ and target labels are unavailable. This should be treated as an extension, not necessarily part of the first
implementation.
4. Why this combination makes sense
 Adaptive preprocessing addresses degraded visual input, especially adverse weather.
 GFO + ALGA improves attention to lane-relevant information and lane geometry.
 CCA adds long-range/global context, useful for night, shadow, glare and partially missing markings.
 Domain adaptation addresses a different issue: the distribution gap between training and deployment environments.
5. Implementation plan for the team
Phase 1: Run original CLRNet as the baseline and reproduce its evaluation.
Phase 2: Add adaptive/fuzzy preprocessing and compare against baseline.
Phase 3: Add GFO + ALGA and evaluate again.
Phase 4: Add CCA after the selected feature level/FPN stage and evaluate difficult scenarios.
Phase 5 (optional): Add disentangled domain adaptation using an unlabeled target domain.
Required ablation: CLRNet → +Fuzzy → +GFO+ALGA → +CCA → all modules. Report overall metrics and
difficult-condition metrics separately. If UDA is added, compare source-only vs adapted model and report FP/FN as
well.
6. Important caution
Do not simply copy all four papers into one network and claim novelty. The team should implement the modules
incrementally, check compatibility and computational cost, and define one clear research contribution. CCCNet itself
reports that global attention improves difficult scenarios but notes computational/generalization limitations; the UDA
paper also shows that naive adversarial alignment can cause negative transfer, so domain adaptation must be

7. Final conclusion to send to the team member
We reviewed four recent approaches for robust lane detection. The literature suggests that robustness can be
improved at four complementary levels: adaptive input preprocessing, lane-aware feature refinement, global
contextual attention, and domain adaptation.
Based on this review, the most practical main model is: Adaptive/Fuzzy Preprocessing + CLRNet + GFO + ALGA +
Criss-Cross Attention (CCA). The domain-adaptation module can be added as an advanced extension for sim-to-real or
cross-domain generalization.
The research question is: Can adaptive input enhancement combined with lane-aware feature refinement and global
contextual attention improve lane-detection performance under unseen adverse conditions?
The implementation should be incremental with ablation experiments so that the contribution of every
component is measurable.
